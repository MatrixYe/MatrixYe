## What I build

**Multi-chain DEX data infrastructure** — full-history backfill + real-time streaming and
indexing for Uniswap v2/v3, Raydium, Cetus and Turbos across Ethereum / EVM chains,
Solana and Sui.

**CLMM market making** — designed and operated a production concentrated-liquidity
market-making system on Sui (Bluefin, Cetus), including its on-chain data plane,
execution engine and monitoring.

**Solana tooling** — published Python SDKs for Jito and Jupiter V6, both distributed
on PyPI.

**Bitcoin protocol** — reimplementing Bitcoin from scratch in Rust: SHA-256, BigNum,
block & transaction structures, Merkle tree, mempool, proof of work.
